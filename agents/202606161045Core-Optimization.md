# papalysaver 核心架構與功能開發白皮書

本文件整合了 `papalysaver` 專案當前的核心優化痛點、產品健壯性防禦機制，以及下一階段必須完工的「動態擴充功能圖示（Extension Icon）」關鍵視覺提示功能。

---

## 一、 核心架構：本機緩存區 (Local Caching)

目前效能瓶頸在於每次操作皆同步等待遠端 API 回應。必須全面改為「本地優先，背景同步」機制。

### 1. 導入 `chrome.storage.local`
* **現狀痛點：** 頻繁向遠端 API 請求撈取資料，或在 Manifest V3 環境下使用受限的 `localStorage`。
* **重構解法：** 擴充套件啟動時，將全量書籤資料同步快取至 `chrome.storage.local`。後續所有「畫面渲染」與「讀取操作」直接對著本地快取執行，體感速度將提升至 1ms 內。

### 2. 樂觀更新 (Optimistic UI Updates)
* **重構解法：** 當使用者按下保存書籤時，**不等待遠端伺服器回應**：
  1. 立即將新書籤寫入本地 `chrome.storage.local`。
  2. 前端介面（Popup / Dashboard）立即渲染新方塊（提供瞬間完成的流暢體感）。
  3. 由背景腳本在後台默默向伺服器發送同步請求。若斷網或伺服器崩潰，本地資料依然完好，待網路恢復後自動重試。

---

## 二、 運行機制與網路請求優化

### 1. 善用 Service Worker 非同步特性
* **重構解法：** 將耗時的網路請求（如與遠端進行批次資料同步、抓取網頁 Favicon 標籤）完全移入 Manifest V3 的 Service Worker (Background Script) 中執行，嚴禁卡住 `popup.js` 的 UI 主執行緒。

### 2. 減少不必要的 DOM 重新渲染 (Reflow / Repaint)
* **現狀痛點：** 書籤牆包含大量方塊格（Tiles），若每次增刪都使用 `innerHTML` 刷新整面牆，會造成嚴重的瀏覽器卡頓。
* **重構解法：** 使用 `document.createElement` 針對單一改變的書籤節點進行精準的 DOM 操作，避免全頁重繪。

### 3. 請求防抖與超時控制
* **防抖機制：** 當使用者在短時間內連續儲存多個分頁時，實作 `Debounce` 機制，在操作停止後將變更「打包成單一次請求」批次送出，避免觸發伺服器頻率限制。
* **斷網降級：** 使用 `fetch` 的 `AbortController` 設置嚴格的超時機制（如超過 3 秒未回應即判定失效）。一旦超時或檢測到斷網（`navigator.onLine === false`），立刻切換至「純本機離線模式」，確保使用者操作不受阻斷。

---

## 三、 產品健壯性與錯誤處理 (Error Handling)

### 1. 移除硬性報錯紀錄
* **現狀痛點：** 在 `popup.js` 的 `catch (err)` 區塊中使用 `console.error(err)`，會導致 Chrome 擴充功能管理後台留下難看的紅色錯誤紀錄（Error）。
* **重構解法：** 對於預期內發生的狀況（例如用戶未登入原廠網站或離線），改用 `console.warn` 進行防禦性提示：
  * 當捕捉到錯誤且本地有快取數據時，照常顯示快取內容，維持軟體整潔度與工程品質。
  * 只有在本地完全沒有快取資料的情形下，才隱藏主表單並顯示登入提示。

---

## 四、 未實現核心功能：智慧分頁狀態提示 (Dynamic Icon Status)

此功能為提升使用者體驗（UX）的核心機制，旨在透過擴充功能圖示（Extension Icon）的顏色變化，直觀提醒使用者當前網頁的存取狀態，避免重複儲存。

### 1. 初始狀態（未存取）
* **行為表現：** 當使用者瀏覽尚未存入 `papalysaver` 的全新網頁時，擴充功能圖示必須保持 **「灰色圖示」**。

### 2. 存取動作觸發
* **行為表現：** 當使用者按下套件並成功將當前網頁存入書籤後，圖示必須立刻轉變為 **「粉紅色圖示」**，給予使用者明確的成功視覺回饋。

### 3. 主動偵測與重複儲存提醒（防呆機制）
* **行為表現：** 
  * 當使用者未來打開、切換、或重新造訪任何一個「已經存在於 `papalysaver` 書籤資料庫中」的網站時，背景腳本（Service Worker）必須主動比對網址。
  * 一旦確認該網址已被存取，擴充功能圖示會**直接主動轉成粉紅色圖示**。
  * 透過此視覺暗示，明確提醒使用者「此網站不要再存一次」，達成完美的產品防呆閉環。
